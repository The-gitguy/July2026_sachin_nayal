# Day 15 — Java, S3 Bucket, CronJob, File Reader

## 🔹 Ansible — Install Java & Set JAVA_HOME

---
- name: Install Java on sachin server
  hosts: all
  become: yes

  tasks:
    - name: Install OpenJDK
      yum:
        name: java-11-openjdk
        state: present

    - name: Set JAVA_HOME
      lineinfile:
        path: /etc/profile
        line: 'export JAVA_HOME=/usr/lib/jvm/java-11-openjdk'

## 🔹 Kubernetes — CronJob

apiVersion: batch/v1
kind: CronJob
metadata:
  name: sachin-cron
spec:
  schedule: "*/5 * * * *"
  jobTemplate:
    spec:
      template:
        spec:
          containers:
            - name: job
              image: busybox
              command: ["sh", "-c", "echo sachin CronJob running"]
          restartPolicy: OnFailure

# Advanced Notifications

## 🔹 Jenkins Pipeline — Slack Notification
 **send Slack notifications after build success or failure**.

pipeline {
    agent any
    environment {
        INSTITUTE_NAME = "sachin"
        SLACK_CHANNEL = "#devops"
    }
    stages {
        stage('Checkout') {
            steps {
                git url: 'https://github.com/sachin/sample-java-app.git'
            }
        }
        stage('Build') {
            steps {
                sh 'mvn clean package'
            }
        }
    }
    post {
        success {
            slackSend(channel: "$SLACK_CHANNEL", message: "SUCCESS: $INSTITUTE_NAME Build #${env.BUILD_NUMBER}")
        }
        failure {
            slackSend(channel: "$SLACK_CHANNEL", message: "FAILURE: $INSTITUTE_NAME Build #${env.BUILD_NUMBER}")
        }
    }
}

## 🔹 GitLab CI — Slack Notification
 **notify Slack in GitLab CI**.

stages:
  - build

variables:
  INSTITUTE_NAME: "sachin"
  SLACK_WEBHOOK: "https://hooks.slack.com/services/XXXXX/YYYYY/ZZZZZ"

build:
  stage: build
  image: maven:3.8.1-jdk-17
  script:
    - git clone https://github.com/sachin/sample-java-app.git
    - cd sample-java-app
    - mvn clean package
    - curl -X POST -H 'Content-type: application/json' --data '{"text":"Build success for sachin"}' $SLACK_WEBHOOK
